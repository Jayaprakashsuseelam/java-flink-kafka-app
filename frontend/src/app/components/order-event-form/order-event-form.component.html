What happens when you send an order event?
  1. Order event is sent to Kafka topic "orders"
  2. Flink stream processor picks up the event
  3. Event is enriched with additional data
  4. Enriched order is stored in MongoDB
  5. You can view enriched orders in the "Enriched Orders" section
Required Fields:
  • Order ID: Unique identifier for the order
  • User ID: Customer identifier
  • Item ID: Product identifier
  • Quantity: Number of items (minimum 1)
